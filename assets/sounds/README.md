# assets/sounds/

Notification/wake-word/UI sound effects (`.wav`/`.mp3`), for
`ui/notifications.py` and `voice/` (wake-word acknowledgement,
listening/thinking/done chimes). Keep short (<2s) UI cues here;
longer generated audio (TTS output) belongs in
`storage/cache/voice/` or `storage/cache/tts_cache/`, not here.
